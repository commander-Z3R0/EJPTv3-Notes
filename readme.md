# eJPT Notes

A multilingual, text-based study guide for the **Junior Penetration Tester (eJPT)** course. This repository condenses approximately **250 hours of course content** into structured notes focused on the most important concepts, techniques, tools, and commands.

The material is available in:

- English
- Spanish
- French

The repository also includes practical **tool cheat sheets**, command references, and quick notes for commonly used penetration-testing tools.

> This project is intended for educational purposes and authorized security testing only. Do not use these techniques against systems without explicit permission.
